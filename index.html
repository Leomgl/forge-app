Activer l’édition GitHub

Pour changer l’état d’un ticket dans FORGE, GitHub exige une autorisation d’écriture. Utilise un jeton fine-grained limité à Leomgl/forge-app avec uniquement Issues : Read and write et une expiration courte.

Le jeton reste uniquement dans la mémoire de cette page : il est effacé au rechargement, à la fermeture ou quand tu touches « Déconnecter ». Ne le mets jamais dans un ticket, une capture ou un chat.
